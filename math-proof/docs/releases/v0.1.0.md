# v0.1.0 · 数学证明模式（首个公开版本）

> **一句话**：把「以 **Agda 内核为唯一裁决**、**先算后验证**、**长程证明台账**、**反刷分证据纪律**」
> 装进 [DeepSeek Harness](https://www.npmjs.com/package/@deepseek-ai/dsh) 的 agent preset，
> 让长程形式化证明工作**有记忆、有证据、可接手**。

---

## 这个版本解决什么

形式化证明的长程作业里，模型最容易出的三类问题不是「不会证」，而是：
把没证的东西写成证完了、把上下文压缩当记忆、把难和错混为一谈。
本 preset 用**机器挡**而不是「再写一条纪律」来治它们：

| 机制 | 它挡住什么 |
| --- | --- |
| **证据分档 + 回执签名** | 只有 `proof_compile` / `proof_oracle` 签发的回执算「已验证」（与源码/脚本哈希绑定，改一字符即失效）；模型自报的 evidence 一律标未验证并照常扣分 |
| **先算后验证闸门** | oracle 覆盖不足（`points < domain`）→ **禁止开 Agda**；抽样、线性场上的假阴性过不去 |
| **长程台账 + git 见证** | 删记录 / 回退提交 / 手改评分历史 → `check` 报「历史被改写 / 提交数倒退」 |
| **三道机器闸门** | `PreToolUse` 拦截越过步骤（无回执、依赖未证直接 exit 2）；同一模块编译失败 ≥3 次强制委托；postulate 未声明 → 标 `proven` 时拒收 |

## v0.1.0 的七个亮点

1. **6 个工具**：`proof_dag`（命题/对象台账 + 状态机 + 体检 + 评分 + 知识图谱导出）、
   `proof_compile`（编译 + 指纹分诊 + 签发回执）、`proof_graph`（import DAG）、
   `proof_oracle`（Python 精确整数 oracle + 回执）、`prover_limits`（工具链限制经验库）、`proof_audit`（静态合规）；
2. **判定规则热读**：断链豁免 / 评分权重 / postulate 口径 / 编译分诊都在 `impl/ruleset.mjs`，
   工具**每次调用**重新加载 → **改规则不用重开会话，缓存也不失效**；
3. **`proof_dag action:"doctor"` 自证**：报「插件本体 本实例 hash vs 磁盘 hash」与「规则集 rN/hash」——
   分数与断链数**带版本戳**，不会再出现「会话里用旧规则算分、无法自证」的情况；
4. **postulate 三分类门禁**：`rewrite`（有 `{-# REWRITE #-}` 源码依据）/ `unreachable` / `gap`。
   **`proven` 要求「0 未声明」，不是「0 postulate」**；豁免还要一条人类裁决流水——不许自己给自己发豁免；
5. **编译失败的「结果级分诊」**：堆爆 / 被杀 / 超时这类**没有诊断行**的失败也直接给处方
   （界保持符号化 / `opaque` 阻断归约 / 使用点实例化 / 小界探针）；
6. **信息完整对象层**：对象 = 生成方式 + 载体 + 运算 + 关系（缺 `construction` 直接拒收），
   `graph` 导出带发布 schema 的知识图谱 JSON（AI 与人类双读）；
7. **15 个门禁 / 784 条断言**：一条命令自检，纯 `node:` 内建模块、零依赖，裸环境（CI）里也能跑。

## 装（三选一）

**A. 克隆 + 配 root（推荐；`git pull` 即更新）**

```bash
git clone https://github.com/clearnature/dsh-math-proof.git ~/src/dsh-math-proof
```

```yaml
# ~/.dsh/profiles/web/cordis.patch.yml
- id: agent-presets
  config:
    roots:
      - path: ~/src/dsh-math-proof
        trust: user
```

**B. 拷进用户目录**（一次性快照）

```bash
cp -r dsh-math-proof/math-proof ~/.dsh/.agent-presets/math-proof
```

**C. Release 离线包（不用 git；也便于内网传输）**

```bash
curl -LO https://github.com/clearnature/dsh-math-proof/releases/download/v0.1.0/dsh-math-proof-v0.1.0.tgz
sha256sum -c dsh-math-proof-v0.1.0.tgz.sha256     # 先校验
tar xzf dsh-math-proof-v0.1.0.tgz -C ~/src/dsh-math-proof
# 再按 A 配 roots；或直接 cp -r math-proof ~/.dsh/.agent-presets/math-proof
```

> **本版本不发布 npm 包**（账号受限）：`package.json` 标了 `private: true`，且没有任何工作流会执行 `npm publish`
> （`release.yml` 里有 `grep 'npm publish'` 的反向检查）。GitHub Release 只附离线包与校验和。

三条路都需要**重启 / 重挂 dsh**，新建会话时选 `math-proof`（显示名「数学证明模式」）。

## 诚实边界（这个版本不声称什么）

1. 仓库里**没有数学定理的证明**——preset 是工作模式，证明目标来自你自己的库；
2. **本地 git 见证 ≠ 不可篡改**：它提高成本并留痕（`check` 会报历史被改写），真正的不可篡改需要外部只追加日志（未实现）；
3. **工具链限制不计入能力评价**：Agda 版本的 `--rewriting` 传染性检查、堆上限这类问题记在 `prover_limits` 里，
   但失败仍然是失败——处方给了，做不做得到是另一回事；
4. 评分**不是成绩单**：低分不惩罚，`refuted` + 诊断、`blocked` + 原因、写 `handoff` 都是正经交付；
   **分数不能通过改记录提高**；
5. **不发布 npm 包**（账号受限）：装法只有 clone+roots / 离线包 / 拷贝三种；`package.json` 为 `private: true`，
   无运行时依赖、无生命周期脚本。

## 数据与隐私

- 台账、回执、见证、历史、经验库都写在 `~/.dsh/state/math-proof/`（按工作区路径分桶），**不写进项目仓库**；
- 状态里含你的工作区绝对路径哈希与命题文本——**不要把 `~/.dsh/state/math-proof/` 提交到公开仓库**；
- 发布树与 npm 包都排除 `state/` 与机器生成物（`publish.mjs` 会体检：绝对路径 / 疑似密钥）。

## English summary

**dsh-math-proof v0.1.0** — an agent preset for [DeepSeek Harness](https://www.npmjs.com/package/@deepseek-ai/dsh)
that runs long-horizon formal proofs with **Agda as the sole judge**: compute-then-verify oracle gates,
tool-signed evidence receipts bound to source hashes, a persistent proof ledger with a local git witness,
information-complete object nodes with a published knowledge-graph schema, and a hot-reloadable rule set
(`impl/ruleset.mjs`) that reports its own version stamp (`proof_dag action:"doctor"`).
15 self-check gates / 784 assertions, zero npm runtime dependencies, MIT.
Honest limits: no theorems are shipped, the local witness is tamper-evident but not tamper-proof,
and toolchain limits are recorded, not excused.
