### 0. 外层流程（研究系统，非平凡目标先走）
**先声明模式**：形式化模式（路线已知 → `proof_dag` 调度 DAG + 复用 + 逐节点验证）vs 发现模式（路线未知 → 四路并行 + 三筛 + 反例淘汰）。
**拆解**（子问题必须写成可判定/可证伪陈述；陈述先行）→ **四路并行**（构造 / 文献 / 反例 / 形式化；每路带 schema，结论需第二路证据）→ **三筛**（律筛 / 约束筛 / 可判定筛）→ **证明图**（`proof_dag` 状态机 + `next` 调度 + `check` 体检；`proof_graph` 解析 import DAG 给 leaf-first 编译顺序）→ **G/C/R/V**（Generator → Critic → Repair → Verify）→ **记忆**（`proof_dag` 台账 + `memory/*.md`）。
**铁律**：节点只有 `proof_compile` exit 0 + 0 postulate/hole 才可标 `proven`（证据写进 `evidence`）；外层产出没有内层证据 = **猜想**，不是证明。详见 `research-system` 技能。

### 0.5 长程任务纪律（可能连续数天，马拉松不是一次性问答）
**阶段交付**：探索（信息检索 / 参考方向）→ **架构蓝图**（定义层 → 引理层 → 主定理；先定依赖图再动手）→ 依赖图定稿（`proof_dag` 节点 + `deps` + `source` 溯源）→ 逐节点证明 → 审计与记忆。每阶段都留下可被「下一天 / 下一个会话」接手的证据。
**每阶段收尾**：(a) `proof_dag check` 看**完整性评分与趋势**（评分低不是证明错，是「经不起考验」；回退必须解释）；(b) 落证据或诊断；(b) `journal` 记流水（`decision` 裁决 / `source` 文献来源 / `limit` 限制命中 / `milestone` 阶段交付 / `handoff` 跨天交接 / `lesson` **策略教训**：症状→判据→做法→证据）；(d) 「台账↔代码断链」清零；(e) 收工写 `handoff`。
**接手先跑** `proof_dag action:"brief"`（目标 / 可开工 / 卡点 / 待裁决 / 建议下一步），按简报继续；**不要凭记忆重建上下文**。
**向人类学者学习**：关键命题必须带 `source`（文献 / 定理名 / 人类学者策略，精确到文件:行）。学的是**方法与结构**，不是抄结论；引用不可追溯 = 没学到。
**依赖图经得起考验**：声明依赖却未 `import` = 纸面依赖（`check` 会报断链）；上游签名一改，下游全部 `needs_review`——**证明链不断链优先于单个节点漂亮**。
**证明器限制 → 软件经验**：撞到工具链限制先 `prover_limits query "<报错原文>"`；确认是新限制就 `add`（**证据必填**）。限制是软件经验，不是你能力的上限。
**计算是工具，不是裁决**：精确整数计算（**含大数**——库里已有 3 的幂表排到 68630377364883、`3^735` 状态计数、定点整数 `56632/65536`）**允许且必要**，用于反例发现 / 猜想生成 / 约束来源 / 有限穷举的完备性论证；禁止的是「**用算出来的结果当证明**」与「>27 case 穷举冒充构造」（后者必须符号化，见第 2 节）。搜索同理：只找反例与猜想，裁决永远是 Agda。
**待裁决不自行选边**：文档与代码冲突、口径分歧 → `journal` 记 `open:true` 请人类裁决；裁决后用 `journal resolve` 关闭（待裁决只增不减 = 没有闭环）。
**节点不是噪音**：没有陈述 / 没有来源 / 没有证据 / 没有诊断的节点不是节点，是噪音——四样缺一，就别写进台账。

### 0.6 分数是仪表盘，不是成绩单（反刷分纪律）
**评分衡量的是「证据链的健康度」，不是你的表现分。** 低分不惩罚；**隐瞒、伪造、删记录才是失败**。
**只有工具签发的回执算「已证」**：`proof_compile` 成功后签发回执（与源码哈希绑定，改一个字符即失效）。模型手写的 `evidence` 字符串一律标「未验证」并照常扣分——这不是不信任你，而是**让「未验证」这件事可见**，避免把「看起来做完」当成做完。
**诚实动作计为产出，不计为失败**：`refuted` + 诊断、`blocked` + 原因、`handoff`、声明缺口、请人类裁决，都是**正经交付**。证明做不出来不丢分；把它写成做出来了才丢分。
**禁止（最严重违规）**：删除或改写台账 / 评分历史 / 回执；**回退或重写 git 见证提交**；手写 `evidence` 冒充编译证据；自行关闭 `open` 的待裁决；把工具链限制记成「已解决」。台账的每次改动都会自动提交进本地 git 见证仓库（`witness-<hash>`），`check` 会核对「上次检查点是否仍是当前 HEAD 的祖先」——删记录会留下不一致，藏不住。
**环境归因**：编译器 / 沙箱 / 工具链的限制（见 `prover_limits`）**不计入对你的能力评价**，写进 `journal(kind:"limit")` 即可。
**若被要求「把分数提上去」**：正确回答是「分数由证据驱动，不能通过改记录提高」——先补 `proof_compile` 回执或修真实断链。
**引用分数 / 断链数必须带版本戳**：输出里 `规则集 rN/hash` 与「插件本体 hash」是这份结果的**适用范围**。判定规则（断链豁免、评分权重、postulate 口径、编译分诊）在 `impl/ruleset.mjs`，**静态 import（冷档）**——改规则要**重启 dsh 进程**；`doctor` 会报「磁盘 hash vs 进程内 hash」，两者不同说明没重启。两者不一致时先跑 `proof_dag action:"doctor"`——**它自证本实例跑的是哪版**。绝不要拿「本会话旧实例算出的分数」去解释磁盘新规则下的断链数（真实事故：旧实例报 85/100、断链 25 条，磁盘新规则算出来是 0 条）。

### 0.7 三道闸门（把「下次别这样」变成机器挡）
**① 先算后验证闸门（硬）**：任何新陈述进 Agda 之前，用 `proof_oracle` 跑 oracle 穷举（δ 基 / 结构穷举，≤1 分钟）——**先 `proof_oracle action:"kit-list"` 复用共享库**（GF(3)/T⁶/δ 基/CRT/manifest/预计算，别重复造轮子），写完 `action:"kit-lint"` 再跑。脚本必须打印 `ORACLE-MANIFEST {"basis":…,"domain":N,"points":M,"claim":…}`；**`points < domain` 判为抽样，不算验证**（线性场 `f = xᵢ` 上 `Δf ≡ 0` 会骗过你）。回执 id 写进节点 `oracle` 字段，`check` 会报覆盖；oracle 不过 → **禁止开 Agda**。
**② 编译预算闸门（硬）**：同一模块累计编译失败 **≥3 次** → 停止逐条改错，按 `agda-proof-engine` §5.9「编译失败的批量修复协议」批量分诊修复（若环境存在 `loop-engineer` 技能可委托它；该技能不随本仓库分发）。`proof_compile` 报告与 `proof_dag check` 都会打出 `🛑 编译预算闸门`，看到就换手，不要 whack-a-mole。
**③ 编译面闸门**：待证引理先放**探针模块** `_Probe*.agda`（只 import 必要模块，几秒编译），跑通再并入主模块（几分钟）。改 `Base/Trit.agda` 这类被全库依赖的模块前先想清楚：会让 300+ 下游接口失效。
**模式切换闸门**：发现模式下，**反例路线判定回来之前不写正式证明项**；`proof_dag` 里 discover 节点未定，就不要把下游节点标 `active`。
**缓存前缀纪律**：persona / 纪律段 / 工具描述与 schema 是缓存前缀，**禁止出现时间戳、随机数、pid、临时路径**；改插件或技能 = 打穿所有会话的缓存（一次全价）→ 长程会话中批量改、改完开新会话。工具输出只追加、不改写历史；跨天续接走 `brief` + 新会话，别指望压缩免费（压缩会改写前缀 → 缓存必冷）。详见 `CACHE.md`。

### 1. 证明工作流
0. **先算后验证（zcode 方法论）** → 需要探索规律 / 找反例 / 核对大规模枚举时，先用 **Python 精确整数**计算（`engineering/` 轨道，禁浮点）作为**猜想生成器 / 约束来源 / 对抗验证器**；Agda 是**唯一裁决**，Python 通过 ≠ 证明。模型必须保留全部结构分量（无信息截断）。详见 `compute-then-verify` 技能。
1. **读需求** → 确定模块位置与依赖方向（`RootMath → Base → Algebra → Arithmetic → Format → Structology → Constitution → Coupling → Density`，禁止反向依赖）。
2. **先查再断言** → grep 现有模块是否有可复用引理。禁止对已存在的定义写 postulate（连续统污染）。
3. **读 docs（禁止信息截断）** → 涉及群 / 代数结构时，先读 `docs/duodecimal/` **全 24 份**（定位见 `duodecimal-corpus` 技能；权威定义 11/12/20，术语红线 08，本体论 01，零冥族 04，代数复数 09，范数坍缩 10，FLT 裁决 13/15/16，证明状态 07，全绿/待核对 19a/19b）与 `memory/crt-wave-physics-not-modular-arithmetic.md`：确认这是**展示群（生成结构）**还是**投影**，术语是否合法。跳过 docs 直接写证明 = 信息截断。
4. **读源码** → 确认现有类型、引理、证明风格（穷举 / 代数链 / 结构实例），并核对 docs 与源码是否一致。
5. **读 wiki** → `{{wiki}}/` 确认数学依据与实验锚定。
6. **写证明** → 按第 2 节策略优先级选择范式。
7. **编译** → `proof_compile`（或 `agda --guardedness <Module>.agda`；命令行**不加** `--rewriting`，文件头保留 `{-# OPTIONS --rewriting --guardedness #-}`）。
8. **审查** → 用 `proof_audit` 审计，再报结论。

### 2. 证明策略优先级（遇阻塞按序下移，不要跳级）
0. **展示群第一原理**：先判定对象是**生成结构**还是**投影**。结构 = 生成方式（载体 + 生成元 + 关系 + 相位 + 时钟 + 归零 + 刚性）；`12 = lcm(3,4)` 是推论，不是定义。定义与术语红线见 `type-theory-presentation` 技能。
1. **结构实例化（投影层）**：把对象写成 record 结构（载体 / 运算 / 单位 / 逆 / 定律），再在结构层推导；定理优先表述为结构保持映射的交换图。注意这是**投影层工具**，不能替代展示群定义。
2. **CRT 正交分解（投影层技巧）**：`Z/12Z ≅ Z/3Z × Z/4Z`（**投影层**同构，非本源）。12 项操作分解为 3+4 正交分量（≤5 步），优先于 11 步 `trans` 链。复用 `Algebra/Duodecimal.agda` 的 `crt12`/`π3`/`π4`/`crt12-roundtrip`。
3. **代数推导链**：`≡-Reasoning`，每步一个具名引理，`begin/∎` 对齐。
4. **穷举法**：论域有限且 **≤27 case**。先用单位元 / 对称性约化 case 数。
5. **否定证明**：`¬ P` + `λ ()` 空模式匹配。
6. **Postulate 防火墙**：仅当 (a) 论域无限、(b) 编译器级限制、(c) 实验已确认待构造性闭合。必须标注来源与「为何不是定理」。

**复用优先**：写新引理前先 `proof_dag action:"search" query:"…"`（查台账+对象层）；命中的 `proven` 直接引用（`cong`/`subst`/`≡-Reasoning`），`refuted` 别重走，库里没有的才新写。**重新证明已有引理 = 浪费**。
**有限离散是基座，不是上限**：连续对象可以作为**被诊断 / 被投影的对象**进入框架（如 ℝⁿ 挂谷病态、连续统 NS），但基座与裁决仍在离散展示群；可迁移的构造性成果（如 Lean 的纯 ℕ 算术模块）应当吸收——不要因为「离散」就拒绝。
**节点粒度**：一条引理 = **一个能独立写出的顶层类型签名**（能单独放进探针模块编译）。过粗不可证、过细是噪音；`proof_dag add` 的 `statement` 必须能直接变成 Agda 的 `name : Type`。
**>27 case 的穷举是暴力计算，不是构造性证明。** 必须做符号化改造：let-free 归约 + 半线性/线性基展开（`Semilinear`/`Linear` + `semilinear-ext3`/`linear-ext3`），把「有限域上两个映射相等」降为「基上相等」。

### 3. 未来态锚定（PR #8611 方法论）
锁定目标态（RHS / Delta）作为锚点，在其上做正交分解推导；**不要**从源端（LHS / Gamma）逐项剥离、重排。不写 11 步 `trans` 回溯链。

### 4. 硬性禁止清单
- ❌ **信息截断**：把展示群降格为「集合论群 = 12 元素 + 运算表」；把 `C₁₂` / `R₁₂` / `Doz` 投影当本源；把相位（C₄ 位置）或时钟（`mixedOp^12` 走一圈）降格为静态标签。
- ❌ 笼统写「基于 Z12 的代数极」——必须写 DC / C₁₂ / R₁₂ / Doz 之一；说「DC 同构于 C₁₂」前先问：这是同构还是**有损投影**？
- ❌ 把「12 进制」当有限域：**`R₁₂` 是环、不是域**（零因子 `2×6≡0`、`3×4≡0`，`Duodecimal.agda:382-390` 已证）；`GF(3)` / `GF(9)` 才是有限域；`Doz` 只是**记数法**。三者不可混写。
- ❌ 把相位层约化为 {±1}（C₄→C₂ 非忠实商）当合法同余——这是结构性语义错配，不是精度损失（相位不可约性元公理）。
- ❌ 用 `refl` 穷举冒充构造（如 `chern2Proof = refl` 让编译器暴力求值证陈数=2）——`refl` 只确认定义自洽，不产生结构。
- ❌ `Data.Complex`（违宪）；无理数用代数数（`Sqrt3`/`Sqrt2`，定点整数比）。⚠ 定点值 56632/65536 ≈ √3/2 ≠ √3（库内注释矛盾，引用前核对）。
- ❌ 用「进制」论证数论命题（进制不改变数论性质）；不断言完整 FLT——本框架只证「幂的律」（T8：偶次 ⟹ 3|abc）。
- ❌ 为凑编号/凑层数制造假证明（DC12 L5 位数分离已被反例 a=b=9,c=10,n=3 击穿；L7 不可证）。
- ❌ 把「编译通过」当「物理正确」；待核对项不得当作已证。
- ❌ 在连续统上硬做（ε-δ / 极限 / 不可数覆盖 / 非紧空间 / `Choice`）——先跑三重完备性标尺；判为病态则**换离散基座**，不要在连续统内堆证明。
- ❌ 把 Python 计算结果当证明（算术冒充证明）；Python 只作猜想/约束/对抗验证，裁决永远是 Agda `proof_compile`。
- ❌ 把「搜索 / 枚举到没找到反例」当证明；有限穷举必须给出**完备性论证**（构造子穷尽 / 有限类型），否则只是抽样。
- ❌ 把本框架的 CRT 当模运算定理、把 `orbitStabilizer` 当等式/同构——它是**物理波系统 / 谱投影**（729 格点空间域 → 12 陪集频率域）。
- ❌ 浮点数 / 超越函数：`Float`、`Double`、`primFloat`、`pi`、`sqrt`、`cos`、`sin`。无理数用定点整数比。
- 其余 13 条细则（编译 / 语法 / 依赖登记 / 工具链等）见 `agda-proof-engine` 技能的 `references/redlines.md`——**它们同样是硬约束**，只是按需加载。

### 4.5 陈述层自检 / 有界实例化 / postulate 口径（三条硬判据）
**写进模块之前先问**：① 陈述里有「函数相等」吗？无 `funext` 只能写**逐点**形式 `∀ x → f x ≡ g x`，从逐点推整体**正是 funext**（真实事故：NSE.T15「任意 step」版不可证）。② 假设删到不能再删还成立吗？③ 边界点（`n=0` / 空类型 / 最大元）用 oracle 先打一遍。陈述有误 → `diagnosis: statement_wrong` 改形式化，不要硬证。
**界先符号化，且**：真凶不是「界是字面量」，而是**含具体数字递归的「定义体」被展开**——实测 `proj₁ (pigeonhole-fin (12 ^ 729) f)` 单独编译 **3.2s exit 0**（字面量界不爆），但 `stateEnc` 的定义体（含 `enc12 729`）一展开就是 729 层 → 346s 堆爆；**只封界（`abstract N729`）仍 339s 堆爆**。修法：把界与**所有相关定义连同它们的体**封进**同一个 `abstract` 块**，只对外暴露类型，块内 `refl` 证 `N729 ≡ 12 ^ 729` 供块外 `subst`。**抬 `+RTS -M` 是歧路**（不是 OOM，是求值）。
**超时分两类，别混**：① **stdlib 接口重建**（日志尾部在 `Checking Data.*`、`_build` 下大量 `.agdai` 被重写 → 沙箱写不了 stdlib 目录）——**环境问题**，记 `prover_limits: sandbox-stdlib-write`；② **定义体展开**（日志干净、直奔你的模块）——真问题，按上面封装。`proof_compile` 的**结果级分诊**会给出对应处方与「**不是这条**」的反例。
**postulate 口径**：`proven` 不要求「0 postulate」，要求「**0 未声明**」。标 proven 前用 `postulates:[{name,kind,reason}]` 逐个声明：`rewrite`（项目已论证的 REWRITE 语义设计，如 `div3k`/`mod3k`/`gf3Toℕ-A4-inv`）/ `unreachable`（已知无害项）/ `gap`（**真缺口 → 不能 proven，标 blocked + diagnosis**）。工具按源码核对名字：未声明直接拒收，声明不存在的名字报「记录不实」。`rewrite`/`unreachable` 还要**一条人类裁决流水**（`journal` 的 decision，node 指向该节点）——豁免不能自己发给自己。
探针/草稿文件（`_Probe*.agda` / `_test_*.agda` / `*.bak`）**用完删除**，`check` 会列出来；确有用途就在 `journal` 说明。
> 三次事故的完整复盘与处方清单：`skills/agda-proof-engine/references/bounded-instantiation-and-postulates.md`

### 5. 编译失败处理
遇到编译错误**不要逐错误 whack-a-mole**。按 `agda-proof-engine` §5.9「编译失败的批量修复协议」批量诊断闭环（预检 → 六类指纹诊断 → 批量修复 → 编译 ≤5 轮），返回 `状态: DONE | BLOCKED | ESCALATION_REQUIRED`；**若环境存在 `loop-engineer` 技能（通用修复引擎，不随本仓库分发）可委托它**。

六类错误指纹速查：
- A 类 `NotInScope`（stdlib 符号）→ 补 `using`（`Bool`/`true`/`false`/`_≥_`/`_≡ᵇ_`/`s≤s`/`_⊎_`）。
- B 类 `NotInScope`（Sovereign 符号）→ 修正模块路径。
- C 类 `AmbiguousName`（`zero`/`suc`/`_+_`）→ renaming（`fzero`/`fsuc`/`_+ℤ_`/`_+ℚ_`）。
- D 类 `InfectiveImport`/`SafeFlagPragma` → 命令行不加 `--rewriting`。
- E 类 `ParseError`（`postulate ... where`）→ 拆成独立 postulate 块。
- F 类 `UnequalTypes`（`Set` vs `Set₁`）→ 提升类型层级。

### 6. 对抗验证协议（发现论证空洞的唯一可靠手段）
构造性定理写完后，必须在具体点上用独立 `refl` 计算交叉比对：原点 / 生成元 / 混合点 / 同态性 / 结合律。只有具体实例与定理实例一致，才算闭合。

### 7. 元诊断（连续统病态）
**三重完备性标尺**：几何闭包 / 原生共轭 / 描述完备。连续统 ℝⁿ = (0,0,0) 病态；离散 GF(3)ⁿ/GF(9) = (5,2,4) 自愈。
**病态检测规则**：证明中出现 ε-δ / 极限 / 无限细分、不可数覆盖 / 非紧空间、测度为零但非空集、无穷 q-展开表、`Choice` / 排中律 → 连续统病态信号 → **切换离散基座**（用 GF(9) 的 σ(x)=x³，而非 GF(2)）。
**病态量度**：挂谷 127/2 = 63.5；FLT 60478 模块 / 3 个 refl 级定理 ≈ 20000+。
**三个千禧年初诊**：P vs NP `BarrierTrilemmaWithoutDiscreteGlobalEncoding`（几何闭包天然满足，困难在认知屏障）；NS `ContinuousDissipationWithoutDiscreteBarrier`；YM `UVDivergenceWithoutDiscreteCompactification`（通用质量间隙未形式化）。
**诚实边界**：库内是 Dvir 下界的 GF(3) 实例，不是 Dvir 全定理；「连续统是离散刚性的投影」是元诊断立场，非 Agda 定理。详见 `meta-diagnosis` 技能。
